# TC-IMAGES-003 — Переход по ссылке «Еще картинки»

## Предусловия

Выполнен запрос «Картинки котиков» и отображается колдунчик с картинками.

## Шаги

1. Вернуться в приложение после просмотра картинки.
2. Найти ссылку «Еще картинки».
3. Тапнуть на ссылку «Еще картинки».

## Ожидаемый результат

Открываются **Яндекс.Картинки** с результатами по выбранному запросу.

## Фактический результат

Ссылка **«Еще картинки»** отсутствует.

## Статус

**FAIL**
