# TC-TIME-001 — Запрос «Сколько времени?»

## Предусловия
Алиса доступна для взаимодействия.

## Шаги
1. Обратиться к Алисе с запросом: «Сколько времени?»

## Ожидаемый результат
Алиса сообщает текущее время и дату.
В начале ответа может фигурировать слово «сейчас».
Ответ продублирован текстом на экране.

## Фактический результат
Алиса сообщает только время, без даты.
В начале ответа фигурирует слово «сейчас».
Ответ продублирован текстом на экране.

## Статус
**FAIL**
