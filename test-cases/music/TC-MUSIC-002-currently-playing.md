# TC-MUSIC-002 — Запрос «Что сейчас играет?»

## Предусловия

Алиса доступна для взаимодействия.

## Шаги

1. Обратиться к Алисе с запросом: «Что сейчас играет?»
2. Дождаться ответа Алисы.
3. Проверить текст ответа.

## Ожидаемый результат

Алиса отвечает заглушкой: **«Я не знаю, что сейчас играет»**.

## Фактический результат

Алиса отвечает: **«Прямо сейчас ничего не играет»**.

## Статус

**FAIL**
