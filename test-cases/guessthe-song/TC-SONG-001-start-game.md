# TC-SONG-001 — Запуск игры «Угадай песню»

## Предусловия

Открыт основной диалог Алисы.

## Шаги

1. Сделать запрос: «Давай сыграем в Угадай песню».
2. Дождаться ответа Алисы.
3. Проверить открытие навыка и ответ Алисы.

## Ожидаемый результат

В новой вкладке открывается навык «Угадай песню».

Алиса рассказывает правила игры.

## Фактический результат

Алиса открыла навык, но вместо правил игры написала: «Музыка — моя стихия. Напомните мне какую-нибудь строчку из песни на русском языке».

## Статус

**FAIL**
