# TC-SONG-004 — Выход из игры командой «Алиса, хватит»

## Предусловия

Открыт навык «Угадай песню».

## Шаги

1. Сказать Алисе: «Алиса, хватит».
2. Дождаться ответа Алисы.
3. Проверить, что пользователь вернулся в основной диалог.

## Ожидаемый результат

Алиса подтверждает выход из навыка сообщением, например: «Когда будет скучно — обращайтесь».

Пользователь возвращается в основной диалог.

## Фактический результат

Алиса корректно вышла из навыка и вернула пользователя в основной диалог.

## Статус

**PASS**
