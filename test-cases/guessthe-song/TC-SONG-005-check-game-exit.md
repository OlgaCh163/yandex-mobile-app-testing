# TC-SONG-005 — Проверка выхода из игры

## Предусловия

Пользователь вышел из навыка «Угадай песню».

## Шаги

1. Сказать Алисе: «Привет».
2. Дождаться ответа Алисы.
3. Проверить, что игра не продолжается.

## Ожидаемый результат

Игра не продолжается.

Алиса отвечает фразой из болталки, например: «Привет-привет».

## Фактический результат

Игра не продолжается.

Алиса отвечает корректно.

## Статус

**PASS**
