# TC-SONG-003 — Угадывание песни «Группа крови на рукаве»

## Предусловия

Открыт навык «Угадай песню».

## Шаги

1. Сделать запрос: «Группа крови на рукаве».
2. Дождаться ответа Алисы.
3. Проверить текстовый и голосовой ответ.
4. Проверить информационное окно и доступные кнопки.

## Ожидаемый результат

Ответ распознается корректно и отображается текстом на экране.

Появляется информационное окно с цитатой из нужной песни, именем исполнителя и названием песни.

Алиса голосом проговаривает соответствующее текстовое сообщение.

Под текстовым сообщением есть кнопка «Послушать на Яндекс.Музыке».

Под текстовым сообщением есть кнопки лайка и дизлайка.

В качестве дополнительных опций могут быть предложены кнопки для поиска другого варианта с этим текстом, новой строчки и правил игры.

## Фактический результат

Кнопки лайка и дизлайка отсутствуют.

Есть кнопки «Другой вариант», «Новая строчка» и «Правила».

Имя исполнителя и название песни не указаны.

Предложение продолжить игру отсутствует.

## Статус

**FAIL**
