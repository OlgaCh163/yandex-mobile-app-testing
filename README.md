# QA Portfolio — Voice Assistant

Портфолио ручного тестирования голосового ассистента.

В репозитории представлены тест-кейсы и баг-репорты, составленные на основе проверки основных функций голосового ассистента.

## 📁 Структура проекта

```text
qa-portfolio/
├── test-cases/
│   ├── time/
│   ├── weather/
│   ├── music/
│   ├── images/
│   ├── coin/
│   └── guessthe-song/
│
└── bug-reports/
```

### Test Cases

Тест-кейсы разделены по функциональным областям:

* **Time** — запрос текущего времени и времени в других городах
* **Weather** — текущая погода и прогноз
* **Music** — управление воспроизведением музыки
* **Images** — поиск и просмотр изображений
* **Coin** — подбрасывание монетки
* **Guess the Song** — игровой навык «Угадай песню»

### Bug Reports

В папке `bug-reports/` собраны обнаруженные дефекты с указанием:

* шагов воспроизведения;
* ожидаемого результата;
* фактического результата;
* Severity;
* Priority

## 🧪 Виды тестирования

В рамках проекта выполнялась проверка:

* функциональности;
* голосовых ответов;
* текстовых ответов;
* отображения элементов интерфейса;
* навигации;
* игровых сценариев;
* корректности результатов пользовательских запросов.

## 📋 Формат тест-кейсов

Каждый тест-кейс содержит:

* предусловия;
* шаги воспроизведения;
* ожидаемый результат;
* фактический результат;
* статус выполнения.

## 🐞 Формат баг-репортов

Каждый баг-репорт содержит:

* связанный тест-кейс;
* окружение;
* шаги воспроизведения;
* ожидаемый результат;
* фактический результат;
* Severity;
* Priority

## 📊 Результаты

По результатам тестирования были выявлены как успешно пройденные сценарии, так и дефекты, связанные с:

* отсутствием или некорректным отображением информации;
* несоответствием голосового и текстового ответа;
* отсутствием элементов интерфейса;
* некорректным поведением отдельных функций;
* некорректной работой игровых сценариев.
