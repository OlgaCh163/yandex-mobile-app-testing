# BUG-SONG-001 — Алиса не рассказывает правила игры

**Связанный тест-кейс:** `TC-SONG-001-start-game.md`

## Окружение

* Устройство: Iphone 14 Pro
* ОС: ios 27.0
* Приложение: Яндекс
* Версия: 26.8.6, сборка 691

## Шаги воспроизведения

1. Открыть основной диалог Алисы.
2. Сделать запрос: «Давай сыграем в Угадай песню».
3. Дождаться ответа Алисы.

## Ожидаемый результат

В новой вкладке открывается навык «Угадай песню».

Алиса рассказывает правила игры.

## Фактический результат

Алиса открывает навык, но вместо правил игры пишет: «Музыка — моя стихия. Напомните мне какую-нибудь строчку из песни на русском языке».

**Severity:** Minor
**Priority:** Medium
