# BUG-IMAGES-001 — Отсутствует ссылка «Еще картинки»

**Связанный тест-кейс:** `TC-IMAGES-003-more-images-link.md`

## Окружение

* Устройство: Iphone 14 Pro
* ОС: ios 27.0
* Приложение: Яндекс
* Версия: 26.8.6, сборка 691

## Шаги воспроизведения

1. Обратиться к Алисе с запросом: «Картинки котиков».
2. Дождаться появления колдунчика картинок.
3. Вернуться в приложение после открытия картинки.
4. Проверить наличие ссылки «Еще картинки».

## Ожидаемый результат

В колдунчике картинок отображается ссылка «Еще картинки».

При нажатии на ссылку открывается Яндекс.Картинки с результатами по запросу «Картинки котиков».

## Фактический результат

Ссылка «Еще картинки» отсутствует.

Перейти в Яндекс.Картинки через колдунчик невозможно.

**Severity:** Minor
**Priority:** Medium
